# E. coli central metabolism, Wortel et al. (2018)

## Provenance (reconstructed 2026-11-14)

* Network (51 reactions; Carlsson et al. model as modified in the eFCM project, biomass reaction R70 with ATP/ADP
  coefficient 547) and kinetic data (158 values) from the parameter balancing input of the eFCM project (2016).
  The published model (Wortel et al. 2018) has the same data but the R70 coefficient 1641; which is correct is open.
* Equilibrium constants refer to 1 M (eQuilibrator); declared since 2026-11-14 (see `NOTE_standard_concentration.md`).
* Identical copy: enzyme-cost-minimization package, `resources/models/escherichia-coli_wortel_2018`.
* Full history of all versions: the README of the model collection folder `escherichia-coli-wortel-2018` (local model collection of the author).
